# 访谈总结报告

## 一、访谈主题概览

- **创业动机与时机判断**：讨论王小川在2023年初使用ChatGPT后决定再创业的触发点与战略时机。
- **中国AGI发展路径之争**：回应朱啸虎对“大模型公司无场景、无数据、估值贵”的批评，阐述自身差异化思路。
- **技术与产品关系**：探讨TPF（技术产品契合）与“双轮驱动”理念，强调模型能力与场景深度结合。
- **医疗等垂直领域布局**：分析为何选择医疗作为百川的主战场，以及在此方向上的积累与优势。
- **行业竞争格局与关键判断**：评论OpenAI、Sora、大厂做模型等话题，提出“世界模型”“生命模型”等自有概念。

## 二、被访谈人基本介绍

1. **访谈人姓名/职业身份**：王小川，百川智能创始人兼CEO。
2. **教育背景、专业出身**：清华大学毕业，计算机专业出身。
3. **核心工作从业经历**：前搜狗CEO，主导搜狗搜索、输入法等产品，从搜狐内部孵化搜狗并独立运营，使搜狗年收入达70亿元。
4. **参与重要项目、自研模型、任职企业**：创建并领导搜狗（被搜狐孵化后独立）；2023年创立百川智能，发布百川1、百川2模型；曾投资超10家医疗公司（如春雨、小鹿医馆）。
5. **自身资历与本次访谈议题的匹配性**：拥有20年以上互联网技术产品经验，在搜索、输入法领域深耕，对大模型技术（predict next token）有前瞻认知；同时长期关注生命科学与医疗领域，具备技术、产品、商业化的完整经历，使其在讨论中国AGI发展路径时具备发言资格。

## 三、核心观点、讨论主题与案例

### 观点一：AGI之争是“盲人摸象”，自己追求“理想与现实结合”的第三种路径
- **核心判断**：王小川认为当前行业对AGI的认知如盲人摸象——朱啸虎摸到“象腿”（只看商业闭环与PMF），杨植麟摸到“象鼻子”（只看技术理想），而自己试图看全大象，兼顾技术与商业。
- **具体解释**：他认为单纯现实主义（如朱啸虎的赚快钱逻辑）容易错过技术变革机会，单纯理想主义（如追求最伟大模型）则可能脱离应用场景。自己的策略是“理想上慢一步，落地上快三步”——不追求在模型能力上绝对领先（用美国1/10甚至1%成本追赶），但在应用层的落地速度上要比对手快。
- **案例或依据**：以医疗场景为例，小模型搞不定，但百川不执着于做出世界第一模型，而是找到技术能力与场景需求的结合点。类比搜狗经验：方向感好，从技术到产品到渠道到商业化完整经历，但实操层面需要年轻博士的一手经验。

### 观点二：医疗是百川差异化主赛道，巨头与小公司均难入局
- **核心判断**：王小川认为医疗是百川最能构建护城河的方向，大公司因体量大、怕“惹一身骚”而不敢深扎，小公司体量不够，百川作为大模型公司恰好适合。
- **具体解释**：医疗领域不只需要知识（教材），还需要经验（案例）和逻辑（推理能力），大模型涌现的推理能力正好超越上一代深度学习的经验局限。从技术到产品的演进路径是：知识→经验→逻辑。同时，医疗数据不限于医院，还包括论文中的逻辑推导和患者日常数据（RWS，真实世界研究）。
- **案例或依据**：王小川从研究生时期就开始读医学论文，超过计算机论文阅读量；个人投资超10家医疗公司（如春雨、小鹿医馆、齿科care等）；搜狗在魏则西事件后曾提倡做AI医生。百川目前的目标是“用AI为中国供给100万个医生”。

### 观点三：大模型能力差距缩小，竞争焦点转向方向判断与场景落地
- **核心判断**：头部模型公司之间在公开基准测试上的差距已经明显缩小，真正重要的问题不再是“能不能追上”，而是“接下来应该做什么”。
- **具体解释**：当模型能力在主要benchmark上接近后，单纯追求分数提升的边际价值下降。公司之间的竞争会更多取决于产品方向、组织决策、数据选择和应用场景判断。百川2023年战略是“快速跟随GPT”，2024年后转向差异化，心态更从容。
- **案例或依据**：百川2023年6月发第一版模型，8月获国家备案（当年唯一创业公司），9月发百川2；2024年完成长窗口192K、国产化算力合作等。部分中文领域已比GPT-4好。李斌4-5年前曾预言苹果造不出车，类比大厂做大模型同样面临组织惯性问题——苹果有所有要素但10年花100亿没做出来。

### 观点四：反驳朱啸虎“大模型公司无场景无数据”的批评
- **核心判断**：王小川认为朱啸虎的批评只看到局部（应用PMF），而忽略了技术变革中“大场景需要大技术”的可能性。
- **具体解释**：朱啸虎认为大模型公司找不到PMF、人海战术无意义、通用助理是伪需求。王小川认为这是偏见——PMF有快有慢，有的场景（如医疗）小模型搞不定，并不是一张卡能解决。大模型本质是决策/推理引擎，不是动手脚的助理，其价值在于为医生、律师、购物顾问等提供智力服务。
- **案例或依据**：回应朱啸虎关于游戏NPC的质疑：朱只看到一个小部件（NPC），但百川在构建“摩天大楼”——娱乐领域要做“故事引擎”（太虚幻境），而非单个NPC。百川做To B只是阶段性回血方式，核心是超级应用——例如AI医生场景，技术从知识→经验→逻辑演进。

### 观点五：Sora不是世界模型，语言才是AGI的中轴
- **核心判断**：王小川认为Sora只是模拟引擎，未深入物理规律，不能等同于世界模型；智能不来自多模态，主要来自语言本身。
- **具体解释**：世界模型需要学会物理学，以语言为中轴。Sora既不接近AGI理想（应以语言为中轴），也不接近场景，是两头不靠的资源消耗。OpenAI也只是将其作为小团队探索项目而非主线。他在公司内部否决了复刻Sora。
- **案例或依据**：大模型本质是“决策/推理引擎”，不是“皮囊”（如Sora）。王小川自2000年读研时思考物理范式对生命建模的局限，2016年提出预测下一帧视频是AGI，2018年提出机器掌握语言则AI到来。2023年初使用ChatGPT后，认为机器真正掌握了语言，触发再创业。

### 观点六：大厂做大模型面临组织惯性，百川更有灵活性与差异化机会
- **核心判断**：大公司拥有所有要素（人才、资金、供应链），但面临组织惯性问题，难以快速切入深度的垂直场景。
- **具体解释**：类比苹果造车——苹果有所有要素但10年花100亿没做出来（李斌预言验证）。百度、阿里等大厂做大模型同样面临组织与惯性问题。李彦宏说“文心4.0超GPT-4”活在自己幻觉中，不懂GPT也不懂国内模型，问题出在团队汇报失真。
- **案例或依据**：搜狗经历——比百度晚4年、在搜狐内部做搜索，面对Google时微软bing团队称赞不易。2011年搜狗已启动推荐引擎但组织未跟进，后被字节超越。百川团队拥有多位技术联创（含90后），强调需要技术、现实考虑与人文哲学高度的组合。

### 观点七：百川终局是用AGI创造健康快乐，目标形成千万DAU超级应用
- **核心判断**：百川的终极目标是利用AGI在“创造健康快乐”方向上提供普惠知识与服务，优先做好医疗，并在娱乐等领域争取市场份额。
- **具体解释**：公司价值观聚焦“创造健康快乐”，不做广告文案等与终局不符的场景。视此为最后一次创业；若失败，视为“找到自己的过程”，不纠结卖给巨头。
- **案例或依据**：百川用“三级火箭”架构——能力层、场景层、应用层，强调模型能力与场景决定应用成败。医疗方向是团队能独立掌控的第一个超级应用场景。娱乐方向（太虚幻境）以“故事引擎”为核心，驱动多模态和互动。2024年瓶颈：中国在应用跟不上，应先造模型（发动机）再做产品，但上路时两者都得有。

### 观点八：对技术理想主义（杨植麟）的认可与补充
- **核心判断**：杨植麟的多数技术方向是对的，代表技术理想，相信多模态。但王小川认为其只看到技术局部（如压缩智能），未看到TPF和“场景摩尔定律”。
- **具体解释**：技术+场景阶段性结合才是中局，大模型终点不是做“皮囊”（如Sora），而是做“灵魂”（认知/决策引擎）。王小川坚持以语言为中轴，并认为自己比杨植麟更“完整”——同时看到技术远景和商业落地的现实约束。
- **案例或依据**：行业2019年智谱入局，2021年MiniMax入局，2023年王小川入局晚但节奏清晰。百川2023年战战兢兢跟随GPT，2024年过年后转向差异化，心态更从容。核心是“模型应用一体化”——将差异化融入模型而非外部挂载。

## 四、关键术语表

- **Predict next token / 预测下一个词元**：大语言模型的核心任务，通过前文预测下一个字/词。王小川认为搜狗输入法的本质与ChatGPT原理一致，都是做此事。
- **TPF (Technology-Product Fit)**：技术产品契合，强调技术必须与产品场景有效衔接，不是“拿着锤子找钉子”。
- **PMF (Product-Market Fit)**：产品市场契合，指产品符合市场需求，是朱啸虎关注的商业闭环核心。
- **RWS (Real World Study) / 真实世界研究**：将医疗数据从医院拓展到日常生活环境，以支撑完整的生命建模。
- **世界模型**：指能模拟物理规律和真实世界运行的系统。王小川认为Sora未达此水平。
- **生命模型**：用于理解生命现象、辅助医疗健康的模型，以语言模型为基础，融合生命数据。
- **双轮驱动**：技术和对场景的理解同步推进，产品既满足当下又能随模型升级而增强。
- **三级火箭**：指大模型公司的三层结构——底层模型能力层，中间场景层，最上层应用层；认为场景和能力即可决定应用成败。
- **场景摩尔定律**：王小川提出的概念，指随着模型能力提升，能适用的场景范围会持续扩大。
- **数据飞轮**：应用场景积累数据，数据反哺模型提升效果，形成正向循环。
- **强化学习**：机器学习中通过奖励信号让模型学习最优策略的技术，是GPT体系从“压缩智能”升级的关键。
- **Token / 词元**：文本处理的最小单元，模型输入输出的基本元素。
- **AGI (Artificial General Intelligence) / 通用人工智能**：指具备人类水平认知能力的智能体。
- **太虚幻境**：百川对娱乐业务的命名，强调以故事引擎为核心，驱动多模态和互动。
