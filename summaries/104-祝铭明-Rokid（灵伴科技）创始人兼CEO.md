# 访谈总结报告

## 一、访谈主题概览

- **Rokid创业历程**：从阿里内部创业到独立创办Rokid的完整经历。
- **人机交互入口判断**：对手机、音箱、眼镜等不同交互入口的长期判断与选择。
- **阿里生态与投资文化**：阿里早期的投早投小风格、内部创新实验室运作及后来战略转变。
- **创业关键决策**：2019年放弃音箱聚焦AR的艰难转型。
- **AI与AR融合趋势**：对AI时代终端形态的洞察，以及眼镜作为AI载体的必然性。
- **硬件创业方法论**：创业公司的竞争策略、产品定义、产能与融资哲学。
- **行业竞争格局**：大厂与创业公司在AR/AI眼镜领域的竞合关系。

## 三、核心观点、讨论主题与案例

### 观点一：创业成功需要运气，最绝望时的团队信任是基石

- **核心判断**：祝铭明将第一次创业被阿里收购归因于“运气好”，但渡过危机的关键在于团队无条件的信任。
- **具体解释**：在公司资金链断裂、账上只剩4000元、两周后发不出工资的绝境下，团队成员选择相信他并坚持下来，最终等来了阿里的救急投资。在未来的创业中，他反复强调产品、方向正确之外，团队凝聚力是跨越生死的关键。
- **案例或依据**：2009年5月，祝铭明将团队叫到地下室，提出两个选择：要么接受股票继续坚持，要么搬走电脑抵工资。结果周一无人离开，团队选择陪他共同面对危机。

### 观点二：职业生涯围绕“新的人机交互入口”展开

- **核心判断**：祝铭明所有的职业生涯决策，从操作系统到AI，核心都是在寻找和定义“下一个交互入口”。
- **具体解释**：他认为科技变革往往由交互方式的迁移引爆。早期做手机操作系统，是因为移动互联网需要一个新入口；在阿里做M Lab，探索摄像头、麦克风，是在寻找继键盘、鼠标、触屏之后的新交互方式；创立Rokid押注AR眼镜，则是因为坚信眼镜是AI时代最理想的人机交互终端。
- **案例或依据**：M Lab团队主导了阿里最早的二维码、条形码扫描以及“以图搜图”功能，这本质上是将摄像头作为新的人机交互入口，比腾讯更早。

### 观点三：资源禀赋决定了大公司与创业公司的创新路径不同

- **核心判断**：大公司更适合做确定性较强的项目，而面临高度不确定性的颠覆式创新，更适合在独立的创业环境中进行。
- **具体解释**：在阿里内部，做一个需要10亿资金、5年时间、一流人才的高度不确定性项目，对于需要兼顾已有业务和财务健康的阿里来说，是“不公平的”，对兄弟业务团队也不公平。因此，彻底剥离出来，用最纯粹的创业团队和机制去做，成功率更高。
- **案例或依据**：祝铭明在阿里工作四年后选择离开，认为在内部做AR这种不确定性项目，对人对事都不公平。马云也建议他，这次创业大概率需要他把自己所有资产都投进去。最终，他接受了吴妈个人的投资（而非阿里公司投资）。

### 观点四：智能音箱不是AI时代的平台级入口

- **核心判断**：智能音箱因为输入输出通道窄、使用场景受限，无法成为AI时代的入口级平台，只是过渡产品。
- **具体解释**：他认为音箱的交互被限定在“唤醒词”和“回复”，带宽太低，远远不够。且最佳使用场景仅限于卧室或客厅，无法做到“always-on”（始终在线）。当大公司（阿里、小米）开始不计成本打价格战时，他判断这不是平台型产品，不值得继续烧钱。
- **案例或依据**：Rokid早期音箱产品取得成功，但祝铭明敏锐地看到大公司贴钱竞争的趋势，迅速判断这并非他想要的未来战场。天猫精灵的前身正是他在阿里带出的团队做的，但他选择了放弃。

### 观点五：AR眼镜是AI时代最终极的“always-on”终端

- **核心判断**：眼镜是AI技术的理想载体，因为它能实现“随时随地的 always-on”和“信息直达”，是取代手机部分功能的最佳形态。
- **具体解释**：与手机需要解锁、打开APP等“系统成本”不同，眼镜能让用户以最快速度获取信息（如看时间、扫码、消息提示），比手机快2-3秒，并且不打断人际社交。VR只是专用设备（如游戏机），而AR才是能融入日常生活、碎片化使用的通用终端。
- **案例或依据**：祝铭明坚信AI和AR最终会融合。他以翻译场景为例，有显示的眼镜允许用户实时看到翻译结果并随时修正，对话体验流畅；而无显示时，需要等待3-4秒的语音输出，对话会出现5-10秒的空档，体验完全不同。其产品在推荐率、周活跃度和日均使用时长等指标上都非常亮眼。

### 观点六：创业公司必须“敢于为人先”，在巨头“看不上”时建立护城河

- **核心判断**：对创业公司来说，“敢为人先”是必然选择，而“敢为人后”是巨头的优势。要在巨头“看不上”的阶段完成技术和产品的定义与积累。
- **具体解释**：创业公司的资源有限，必须选择巨头短期内不愿意或不敢投入的“高难度”方向（如带显示的AR眼镜），先摘“高处的果子”。当巨头开始“看得见、看得懂”并觉得有威胁时，创业公司已通过创新和生态构建了先发优势。
- **案例或依据**：雷军造手机和汽车，都是在市场启动后，利用成熟供应链发力，这是“敢为人后”。苹果和Meta在推出昂贵的VST（视频透视）头显后，公开承认方向错误，转而投向轻便式或AI眼镜，这让Rokid反而成了该方向最前面的公司，也意味着要承担更多的行业探索风险。

### 观点七：产业链合作与自研OS是硬件创业公司的核心护城河

- **核心判断**：在硬件领域，决定胜负的关键不仅是硬件本身，更是软硬一体的系统优化能力，自研OS尤其关键。
- **具体解释**：单纯硬件的领先优势只有12-18个月，大公司可以用成熟供应链快速追赶。但软件、生态和底层OS的优化，是线性甚至指数级增长的能力，难以被简单复制。自研OS让Rokid能够在不增加功耗的前提下，实现更快的AI响应速度（0.5秒内）、更长的续航（比Meta多1/3），并支持用户自由切换不同AI大模型。
- **案例或依据**：Rokid自研的OS从底层优化，实现了功耗和AI响应速度的双重领先。该公司选择与DeepSeek、豆包、元宝、通义千问等大模型合作，希望构建开放生态系统，避免单打独斗。

### 观点八：硬件产品必须打磨到极致，才能应对公众放大镜般的审视

- **核心判断**：一旦成为公众关注的焦点，产品就不能以“70分”的标准上市，必须以“90分”以上开始，否则负面口碑会迅速反噬。
- **具体解释**：在获得巨大关注后，产品的一举一动都会被放大。一个不满意的人可能在社交媒体上影响无数潜在用户。因此，公司必须对产品提出前所未有的高要求，确保核心体验无硬伤。
- **案例或依据**：Rokid在意外走红后，招聘负责人表示招聘压力巨大，产品发售前必须应对大量关注。祝铭明认为，此前可以通过F码活动让核心用户协助打磨产品，但现在3亿人流量中，只要有1万人说坏话，就能造成巨大影响，所以第一批产品必须做到最好。

### 观点九：创业的本质是“玩乐精神”，在困难中寻找乐趣和内啡肽

- **核心判断**：创业是一场长期的、充满不确定性的黑森林之旅，驱动创业者走下去的应当是对工作和产品本身的热爱，而不是对财富的渴望。
- **具体解释**：真正的长期主义，是把创业当成一种“游戏”，把解决困难视为“升级打怪”的乐趣。这是一种能带来持久成就感的内啡肽型快乐，而非短暂刺激的多巴胺。当遇到困难时，这种源自热爱的精神能让团队坚持下去。
- **案例或依据**：祝铭明形容自己的创业过程“从来没有把困难当成苦”，而是“大家在一起走一段有意思的旅程”。他规划Rokid成功后，会去做深海潜水器，展现了对未知探索持续的“玩乐精神”。

### 观点十：对失败的恐惧大于对成功的渴望，但坚持比结果更重要

- **核心判断**：创业的失败不是公司倒闭，而是被迫放弃自己选择的道路或做出违背初衷的事情。成功的定义是坚持自己选择的路走下去。
- **具体解释**：在创业者心中，成功不是数字上的一夜暴富，而是能够按照自己的意愿和判断，把一个想法变成现实，并让它影响和改善更多人的生活。即使最终未能成为市场第一，只要坚持了内心的方向，也是一种成功。
- **案例或依据**：祝铭明表示，他更担心有人走与Rokid完全不同的路线颠覆他，而不是巨头直接复制他的路径。他鼓励其他创业公司坚持自己内心认可的方向，即使未来他成为那个为他人鼓掌的人，他也完全接受。

## 四、关键术语表

- **Pre-training / 预训练**：在大规模通用数据上训练基础模型，让模型获得广泛的语言、知识和推理能力。
- **Post-training / 后训练**：在预训练后，通过高质量数据、反馈或强化学习等方式进行微调，使模型更符合具体任务和用户需求。
- **Always-on / 始终在线**：指设备持续可用，无需用户唤醒或等待，能持续感知环境并随时提供交互服务。
- **VST / 视频透视**：通过摄像头将外部环境实时显示在头显内部的屏幕，用户看到的实际是数字化的实时画面。
- **System cost / 系统成本**：从用户产生意图到完成操作所需经过的中间步骤（如解锁手机、打开APP等），AI和AR可以绕过或极大缩短这一路径。
- **F码**：邀请码，企业早期限量提供给核心用户用以测试和打磨新产品的一种方式。
- **PMF / 产品市场匹配**：Product-Market Fit，指产品能够精准满足市场需求并产生持续用户价值的理想状态。
- **具身智能**：能够感知物理环境并自主与空间交互的智能体，典型代表是机器人和智能汽车。
- **以定代产**：根据实际订单数量决定产能规模，可避免库存积压，但可能导致需求爆发时产能不足。
