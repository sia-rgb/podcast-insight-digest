# 访谈总结报告

## 一、访谈主题概览
- **DeepSeek崛起之路：** 探讨DeepSeek从低调量化公司孵化到大模型领域的关键节点与成功因素。
- **技术创新路径：** 梳理DeepSeek从基座模型到混合专家模型（MoE）、再到推理模型的持续演进与核心创新。
- **强化学习探索：** 分析DeepSeek在强化学习（RL）应用上的哲学演变，从奖励模型到规则奖励的核心实践。
- **开源与工程文化：** 解析DeepSeek开源、低调、注重长期研究的独特企业风格。
- **行业竞争格局：** 从DeepSeek的实践出发，审视国内大模型行业的竞争现状与未来方向。

## 三、核心观点、讨论主题与案例

### 观点一：DeepSeek的成功源于敢于尝试高风险创新的“勇者”心态与长期主义风格
- **核心判断：** 被访谈人认为，在大模型“百模大战”的浮躁期，DeepSeek能够保持低调、不追求短期KPI，敢于投入资源尝试高风险创新，是其最终脱颖而出的关键。
- **具体解释：** 相比于其他公司受制于短期商业压力和快速出成绩的诉求，DeepSeek拥有更像高校实验室的宽松文化。这使得他们敢于尝试当时业界少有人敢做的创新，如使用远超常规数量的专家数量（160个）、引入全新的MLA机制，以及高风险的大规模FP8训练，而不担心短期失败。
- **案例与依据：** 何俊贤指出，在业界普遍使用8或16个专家的惯例下，DeepSeek敢于将专家数量增至128、160甚至256个，这是一个“勇敢的行为”。同样，他们是大规模语言模型训练中成功应用FP8训练的公开第一团队，这需要解决极其复杂的训练稳定性问题。

### 观点二：DeepSeek的降本增效归功于MoE和MLA两项核心架构创新
- **核心判断：** 被访谈人强调，DeepSeek实现极致成本控制的秘密并非单纯来自工程优化，而是源自于底层的算法架构创新，特别是MoE和MLA。
- **具体解释：** MoE（混合专家模型）通过使用海量专家但只激活极少数，大幅降低了模型前向计算量；而MLA（多头潜在注意力）则通过低秩压缩技术，将KV Cache的大小压缩超90%，极大降低了推理时的显存占用。两者结合，使得DeepSeek V2/V3在极低的激活参数下，实现了超越许多同体量稠密模型的性能。
- **案例与依据：** 以DeepSeek V2为例，其总参数236B，但激活参数仅21B，训练成本降至V1的42.5%，推理速度快了5.76倍。与其对比的Mixtral 8x22B虽有8个专家，但激活参数达39B。被访谈人认为，V2极致的设计引发了国内大模型价格战，且DeepSeek在极低定价下仍有利润。

### 观点三：DeepSeek从早期就展现出了严谨的科研态度，不同于单纯“堆资源”
- **核心判断：** 被访谈人认为，DeepSeek从第一篇论文开始，其风格就不像一家追逐热点的商业公司，而更像一个低调、诚实、追求“理解科学”的高校研究组。
- **具体解释：** DeepSeek发表的论文不仅详细记录成功经验，还会诚实披露他们在“刷榜”等行为上的实验和发现，这种坦诚在业界非常罕见。他们在技术决策上不盲目“follow”，而是希望通过小型实验理解背后的科学原理（如Scaling law和超参数选择）。
- **案例与依据：** 在DeepSeek LLM论文中，团队做了非常细致的超参数scaling study，通过在小模型上实验来获取数据，拟合函数，外推大模型的最优配置。此外，他们作为C-Eval榜单的维护者，证实DeepSeek是极少数公开研究并自愿披露“刷榜”行为的公司，其论文报告中的分数并未经过优化。

### 观点四：DeepSeek的强化学习探索经历了从“弯路”到“大道至简”的演变
- **核心判断：** 在强化学习应用于推理任务的路径上，DeepSeek与社区一样，最初走了一段使用复杂奖励模型的“弯路”，最终收敛到简单、鲁棒的规则奖励，证实了“大道至简”的原则。
- **具体解释：** 早期，社区（包括OpenAI和DeepSeek自身）普遍认为训练一个好的过程监督奖励模型（PRM）是强化学习成功的关键，但这被认为既困难又不稳定。被访谈人团队及DeepSeek的工作最终证明，对于数学、代码等可验证的任务，直接使用基于结果对错的“规则奖励”最有效，完全不需要训练复杂的神经网络奖励模型。
- **案例与依据：** 何俊贤分享个人经历：半年前尝试online RL + reward model，因难以调参而失败。直到看到R1论文，才意识到可以抛弃奖励模型。他提到DeepSeek的Prover系列，其成功的关键就是使用Lean定理证明引擎提供0/1的规则反馈。R1的最终方案也被认为是极其简洁：基座模型 + GRPO + 规则奖励，抛弃了MCTS和奖励模型。

### 观点五：DeepSeek V3在预训练阶段实现了成本与效率的极致平衡
- **核心判断：** 被访谈人认为，DeepSeek V3的预训练工作代表了一种工程与算法结合的极致，以远低于竞争对手的成本，训练出了性能领先的模型。
- **具体解释：** V3的成功并非单一技术的突破，而是多项工程创新的组合，包括首次在大规模模型成功应用的FP8混合精度训练，以及前瞻性的Multi-Token Prediction（MTP）技术。这些技术共同作用，不仅降低了训练成本（557万美元），还保证了训练过程的绝对稳定（零Loss Spike）。
- **案例与依据：** DeepSeek V3仅使用了2048张H800和557万美元的训练成本，而同期Meta的Llama 3 405B训练成本则是其数倍（约六分之一）。V3的激活参数仅30B，却能在推理、代码、数学和中文任务上大幅超越激活参数400B的Llama 3 405B。

### 观点六：DeepSeek对强化学习的应用经历了从结果监督到过程监督的深入探索
- **核心判断：** 在强化学习的具体应用上，DeepSeek不仅关注最终结果，更深入到了对推理过程的监督，但这一探索的最终成果是将“监督”完全交给了规则。
- **具体解释：** 以MaShepherd（MATH-Shepherd）工作为代表，DeepSeek尝试自动化构建过程监督奖励模型（PRM）的训练数据，不依赖昂贵的人工标注。他们通过让模型自行采样并根据后续结果标记每一步对错，数据自动生成效果与人工标注相当。然而，后续R1系列证明，当任务可被规则定义时，过程监督也可由规则完成。
- **案例与依据：** MaShepherd通过让模型继续生成后续步骤，根据最终正确与否标记当前步骤正负，从而自动构建训练数据。实验表明，该自动标注的PRM效果与OpenAI的PRM 800K（人工标注）相似，为社区提供了首个开源的过程监督数学奖励模型。

### 观点七：DeepSeek的持续创新能力源于“组合式创新”和坚持自研技术积累
- **核心判断：** DeepSeek的成功并非来自颠覆性的原创理论，而是通过长期坚持将多项非原创、但前瞻性的技术进行组合，并在工程上做出突破，最终形成显著领先。
- **具体解释：** 被访谈人指出，无论是MTP还是FP8训练，都不是DeepSeek的原创。但他们是第一个大规模把这些技术成功训练成功的团队。这种“勇敢的创新”体现在他们敢于在别人还没验证的领域投入。同时，他们长期坚持自研MoE、MLA、GRPO等核心技术，每次只比主流方案多改一小点，却逐步积累了巨大的系统性优势。
- **案例与依据：** Multi-Token Prediction来自一篇独立的学术论文，FP8训练在此前也未在如此规模的模型上被成功验证。嘉宾认为，DeepSeek的创新是“组合式创新”，其论文风格像学校，低调、务实。这种文化使得他们可以在没有KPI压力的情况下，长期坚持做被视为高风险的事情。

### 观点八：DeepSeek成功证明了“规则奖励” 是强化学习在推理任务上的更优路径
- **核心判断：** 被访谈人认为，DeepSeek R1系列工作的关键价值在于，它清晰地证明了对于可验证的推理任务，简单的“规则奖励”远比复杂的“奖励模型”更高效、更鲁棒、更稳定。
- **具体解释：** 规则奖励基于客观事实（如数学答案对错、代码测试是否通过），没有对训练数据分布的依赖，因而泛化能力更强。而奖励模型需要精心设计、训练和调参，且在分布外容易失效。DeepSeek R1-Zero仅通过规则奖励和RL，就能在AIME等高难度数学基准上实现性能的显著增长。
- **案例与依据：** R1-Zero在没有SFT、没有奖励模型、没有MCTS的情况下，仅靠基座模型V3和规则奖励直接进行RL，在AIME上的得分从0.2/0.3持续增长到0.7/0.8，证明了这条路径的可行性。何俊贤团队也通过自身案例证实：起初尝试PPO+奖励模型失败，之后改用迭代式进化（rejection sampling）成功，最后发现不使用奖励模型的PPO也能成功。

### 观点九：DeepSeek R1论文虽简单，但揭示了大模型推理的突破性方向
- **核心判断：** 被访谈人认为，R1论文是所有DeepSeek论文里最简单的一篇，但其意义重大，因为它将强化学习在推理任务上的应用简化到了极致，并为整个行业指明了方向。
- **具体解释：** 这条路径被总结为：优秀的基座模型（V3） + 强大的强化学习算法（GRPO） + 纯粹的规则奖励 + 有限的冷启动SFT。这一简洁框架摒弃了此前被认为是必需的MCTS、奖励模型等复杂组件，证明了“长思考”能力可以直接从强化学习中涌现出来。
- **案例与依据：** 在R1之前，社区普遍认为OpenAI o1的技术核心是MCTS或奖励模型。R1-Zero的成功表明，这些都不是必需的，甚至OpenAI官方人员后来也承认，DeepSeek的技术路线与o1的思路类似。这证明了DeepSeek对技术趋势的准确判断和强大的执行力。

## 四、关键术语表
- **基座模型 (Foundation Model)**：大模型的基础版本，提供通用的语言、推理等能力，后续可在此基础上进行微调以适配具体任务。
- **混合专家模型 (MoE)**：一种模型架构，将模型分为多个独立的子网络（专家），每次输入仅激活少数专家，从而在保持模型容量的同时降低计算和存储成本。
- **多头潜在注意力 (MLA)**：DeepSeek提出的一种创新注意力机制，通过将Key和Value压缩到低维的隐空间，大幅减少KV Cache的存储，降低推理时的显存占用和延迟。
- **强化学习 (RL)**：一种训练方法，让模型通过与环境的交互、接收奖励或惩罚信号来学习最优策略，用于提升模型的特定能力（如推理）。
- **规则奖励 (Rule-based Reward)**：一种基于预设规则（如数学答案匹配、代码测试通过）直接给模型输出打分的奖励方式，无需训练额外的神经网络奖励模型。
- **奖励模型 (Reward Model)**：一种用于评估模型输出质量的神经网络，在强化学习中作为奖励信号源，但训练复杂且可能不稳定。
- **过程监督 (Process Supervision)**：对模型推理过程中的每一步而非仅对最终结果进行监督和奖励，以引导模型产生更正确和更长的思考链。
- **Group Relative Policy Optimization (GRPO)**：DeepSeek自研的强化学习算法，通过组内样本的相对优势来更新策略，无需价值模型，降低了训练成本。
- **刷榜**：指模型通过专门优化训练数据或后处理过程来提升在公开评测榜单上的分数，导致分数虚高而无法真实反映模型的实际泛化能力。
- **KV Cache**：一种存储历史词元（token）Key和Value向量以加速自回归生成的技术，但其大小会随序列长度线性增长，导致显存压力增大。
- **Multi-Token Prediction (MTP)**：一种训练策略，让模型在一次前向传播中同时预测后续多个token，可以提升训练信号的密度并为推测解码（Speculative Decoding）提供支持。
- **FP8 Training**：使用8位浮点数进行混合精度训练，可大幅降低训练时的计算量和存储成本，但需要解决精度损失带来的训练不稳定问题。
- **Pass@k**：一种评估指标，衡量模型在k次独立采样中至少有一次能成功解决问题（如通过代码测试或得出正确答案）的概率。
