## 三、核心观点、讨论主题与案例

### 观点一：Pre-training决定模型上限，Post-training无法突破
- **核心判断**：访谈嘉宾坚定认为，预训练（Pre-training）是决定模型内在能力上限和涌现新能力的核心阶段。后训练（Post-training）和强化学习（RL）只能激发或加强已存在的能力，无法创造出新的智能突破。
- **具体解释**：在一个能力较弱的基座模型（Base Model）上做强化学习，如同“小学生刷题”，会很快触及天花板。只有通过预训练不断扩展模型的知识广度和推理基础，才能为后续的能力提升提供真正的潜力。当前行业最大的“非共识”就在于此：有人认为“训练结束了”，但嘉宾认为“训练空间还非常大，甚至刚开始”。
- **案例或依据**：嘉宾认为OpenAI看似不重视预训练，部分原因是其战略聚焦于O系列推理模型和ChatGPT的用户增长，导致预训练人才流失。而Anthropic高度重视预训练和基座模型，嘉宾对其在基座模型上取得显著进步“信心前所未有的强”。

### 观点二：编程能力是实现AGI的最优环境
- **核心判断**：编程（Coding）是比搜索引擎、推荐引擎更重要的技术引擎。它是实现AGI最理想的赛博世界环境，是模型的“手”，能够动态执行并反馈。
- **具体解释**：绝大部分现实世界的任务可以通过代码在数字世界中表达和解决。一个精通编程的Agent可以操作几乎所有的数字系统。嘉宾认为，Agent在两年内操作数字环境的能力将超过99%的人类。
- **案例或依据**：Claude 3.5 Sonnet解锁编码能力，直接催生了Cursor这样的明星产品。Cursor已成为编程工具领域的重要力量，每月向Anthropic支付超过1000万美元的Token费用。嘉宾认为，得Coding者得Agent，得Agent者得天下。

### 观点三：AGI将在未来两年内实现
- **核心判断**：访谈嘉宾对“两年内实现AGI”持有前所未有的信心，概率接近百分之百。他认为沿着当前的技术路径（预训练+后训练+Prompt工程）即可实现。
- **具体解释**：嘉宾对AGI的定义是：在90%的行业能够达到90%的专家水平，并且能做90%有经济价值的工作，其环境限定为电脑/数字环境。当前模型在代码、推理和指令遵循等关键能力上的进步速度，已经足以支撑这一判断。
- **案例或依据**：嘉宾参考了AGI“登山路线图”：Chat（GPT-3.5/4）→ Coding（Claude Sonnet 3.5）→ Coding Agent → General Agent → AI for Science。他认为当前正处于从Coding向Agent过渡的关键爆发期，2026-2027年可能是AI for Science的爆发点。

### 观点四：主流AI公司战略观点分化显著
- **核心判断**：OpenAI和Anthropic在技术路径和产品战略上出现了重大分化。OpenAI更依赖推理模型（O系列）和消费级C端产品，而Anthropic则更坚定地押注预训练和B端企业级应用。
- **具体解释**：OpenAI的核心赌注在于通过O系列/推理模型实现AGI，并将ChatGPT打造成了超10亿用户的超级应用，目标是颠覆Google。其组织文化偏向自下而上，更关注流量和营收。Anthropic（TH）的组织文化更偏向自上而下，核心赌注在Base Model和Coding生态。两家的分歧本质是“流量重要还是智能重要”。
- **案例或依据**：嘉宾认为OpenAI可能因组织问题（核心团队动荡，Pre-training人才流失）导致看似不重视Pre-training，过度关注O系列和C端功能。而Anthropic的团队本身是做Training出身，对其更有信心。嘉宾主张认为OpenAI应成为消费互联网公司的投资人观点是错误的。

### 观点五：强应用是模型公司的“盗火者”，但长期面临被内化的风险
- **核心判断**：在当前阶段，像Cursor、Perplexity这样的强应用公司，通过充分利用顶级模型的能力，实现了快速增长，是“模型的盗火者”。但长期看，模型公司自身会内化这些能力，形成竞争威胁。
- **具体解释**：模型能力的提升正在不断挤压应用层的生存空间。当模型原生内置了此前需要通过外部“脚手架”（如代码补全逻辑）实现的功能时，应用层不得不花费时间重新调试，甚至转向自行训练模型。过去两年，聚焦产品而非模型自身的公司多数失败。
- **案例或依据**：Claude Sonnet 3.7模型内置了Cursor此前用到的外部脚手架功能，导致Cursor团队不得不暂停三四周进行适配，并开始招募训练人才准备端到端训练。Perplexity目前未被OpenAI吃掉，主要是因为OpenAI的战略选择和组织能力未优先做联网搜索。

### 观点六：Anthropic的生态潜力优于OpenAI
- **核心判断**：尽管OpenAI在C端和营收上一骑绝尘，但Anthropic（Anthropic）正在构建一个更健康、更强大的B端和开发者生态，其长期价值可能更高。
- **具体解释**：Anthropic的路径是“想成为安卓”，专注于企业级应用、构建强大的基座模型，并赋能整个Coding和Agent生态。而OpenAI“想做苹果”，更关注消费级终端产品。嘉宾认为，Anthropic的Instruction Follow（指令遵循）能力断档领先，这使其在Agent和企业级应用中占据优势。
- **案例或依据**：在Anthropic的生态中，出现了Cursor、Midjourney等成功的大公司。而OpenAI的生态中尚未长出足够大的新公司。嘉宾的假设投资组合中，给予Anthropic 25%的最高权重，同时认为其确定性更高。

### 观点七：组织文化是仅次于算力的核心竞争力
- **核心判断**：在AI领域，灵活、高效、敢于下重注（高“BAT”能力）的小团队组织文化，是比硬件算力更关键的竞争壁垒。
- **具体解释**：一个AGI-native的组织应该具备以下特征：AI First、Research First、有AI一号位、有吸引顶级研究员的机制、敢于下核心判断（BAT）。DeepSeek的成功深刻揭示了这一点。
- **案例或依据**：DeepSeek的启发是，一个灵活的小团队，基于强大的Infra积累，可以创造出让美国硅谷震惊的成果。嘉宾认为，组织文化是判断一家AI公司成败的关键。Sam Altman成功将OpenAI从一个研究组织转变成一家“公司”，也体现了组织文化的重要性。

### 观点八：Agent是第三波AI泡沫，但供给极度受限
- **核心判断**：Agent（智能体）是继Chat（聊天）和Coding（编程）之后的第三波AI浪潮，当前才刚刚开始，但同时也存在泡沫。核心瓶颈不在需求，而在供给，即模型能力和基础设施尚未准备好。
- **具体解释**：真正的Agent需要环境、工具调用、指令遵循、规划、推理、长上下文等多种复杂能力的协同。目前云厂商和模型公司尚未为此做好准备，导致独立落地且表现优异的Agent应用（如Deep Research、Coding Agent）非常稀缺。
- **案例或依据**：Token消耗量可以衡量智能进步程度，从ChatGPT（几千Token/次）到Perplexity（几万Token/次）到mus（七八十万Token/次），能力的跃升对模型调用、长上下文和工具执行能力提出了极高的要求。Agent的智能供给是当前发展的最大瓶颈。

## 四、关键术语表
- **Pre-training / 预训练**：模型在大规模通用数据上进行的基础训练，决定了模型的知识广度、语言能力和推理潜能，是AI能力的“底座”。
- **Post-training / 后训练**：在预训练之后，通过指令微调、强化学习等方法对模型进行优化，使其在对话、遵循指令等特定任务上表现更好，但无法创造新能力。
- **Reasoning Model / 推理模型**：专注于提升模型逻辑推理能力的模型（如OpenAI的O系列），通常通过强化学习在特定任务（如数学、编程）上优化。
- **Base Model / 基座模型**：完成预训练后的原始模型，是后续所有微调和应用的基础，其能力上限决定了整个系统的上限。
- **Agent / 智能体**：能够自主理解、规划、使用工具并执行多步骤复杂任务（如编程、深度研究）的AI系统。
- **Coding / 编程环境**：在本访谈中，被视作实现AGI的核心“赛博世界”，通过动态执行代码并获取反馈，让模型学会与数字世界交互。
- **Tools Use / 工具调用**：模型调用外部API或软件（如浏览器、操作系统）来完成任务的能力，是Agent的关键能力之一。
- **Long Context / 长上下文**：模型一次性处理和理解超长文本（如整本书、数百个网页）的能力，是实现复杂Agent任务的关键技术。
- **Scaffolding / 脚手架**：在模型外部搭建的工程架构和工具链，用于辅助模型完成特定任务，模型能力的提升可能逐步内化这些外部功能。
- **MCP协议（Model Context Protocol）**：模型上下文协议，被视为AI Agent的“TCP/IP”，由Anthropic支持，旨在标准化AI应用与外部工具的连接方式。
