# 访谈总结报告

## 一、访谈主题概览

- **创业历程与生死考验**：Lovart创始人陈冕复盘创办AI应用公司两年间的起伏经历。
- **AI行业认知与变革定位**：讨论AI作为“智能化”革命，与移动互联网的本质区别。
- **竞争策略与融资经验**：分析AI创业者在补贴战、融资节奏、现金流管理上的关键教训。
- **产品迭代与PMF路径**：从第一代图像生成产品到第二代垂类Agent产品的进化逻辑。
- **组织管理与团队文化**：探讨AI时代团队结构变化、创业领导力与团队凝聚方式。
- **个人成长与创业心态**：分享创业驱动力、对成功与失败的感悟，以及给后创业者的建议。

## 二、被访谈人基本介绍

1. **访谈人姓名/职业身份**：陈冕，拉瓦（Lovart）创始人。
2. **教育背景、专业出身**：2014年本科毕业，大学期间大二曾创业做中国版Groupon，后因认知到不适合而终止。
3. **核心工作从业经历**：2014-2019年在滴滴、摩拜、每日优鲜等公司负责产品增长相关工作；之后加入字节跳动，参与瓜瓜龙教育业务、剪映等产品从0到1的建设，经历业务高速增长与双减政策结束；2023年离职创办Lovart。
4. **参与重要项目、自研模型、任职企业**：曾任职于滴滴、摩拜、每日优鲜、字节跳动；在字节跳动参与瓜瓜龙教育产品与剪映等业务；2023年创办Lovart，推出图像生成AI产品与第二代垂类设计Agent产品Lavert。
5. **自身资历与本次访谈议题的匹配性**：拥有连续创业经历与大型互联网公司产品增长经验，亲身经历AI创业从0到1的全周期（融资、补贴战、产品下架、濒临断粮、翻身走红），对AI应用创业的认知与实践具有一手深度发言资格。

## 三、核心观点、讨论主题与案例

### 观点一：好的商业模式应尊重常识，不依赖无限补贴

**核心判断**：陈冕认为，判断业务能否持久发展，需回归商业常识，如独立存活能力、毛利率、单位经济模型，而非仅看规模增速或用户量。

**具体解释**：通过亲身参与摩拜、滴滴等经历，陈冕认识到共享单车和打车生意在补贴战中虽然规模增长快，但本质是“无限供给、忽视成本”，导致业务长期不赚钱。好的商业模式应在没有外部输血时也能自负盈亏。

**案例或依据**：摩拜案例中，陈冕参与一线战斗，发现账算不过来（breakeven无法实现）；在每日优鲜发现“互联网+零售”对低毛利零售改进有限，线上对效率提升不可持续。这些经历让他形成“先算清楚终局”的决策习惯。

### 观点二：AI革命不同于移动互联网，是“智能化”底层变革

**核心判断**：AI（尤其是大模型与扩散模型）不是移动互联网的延伸，而是像电脑发明一样的“智能化”革命，比移动互联网更底层、更重大。

**具体解释**：移动互联网主要拓展场景（线上化），而AI（智能化）改变了信息的生成、处理和交互方式。陈冕认为不能以移动互联网的发展范式来推演AI，比如认为“先做工具，再做搜索，再做社交”的逻辑在AI领域可能不成立。

**案例或依据**：2022年底，陈冕看到王会文发英雄帖后深受触动，判断“这是比移动互联网更大的机会”，并形容为“被救赎”、“希望是一切痛苦的解药”。他类比80年代电脑时代：先有Office/Adobe等生产力软件，再有搜索，最后才到社交娱乐，以此推断AI应用也应优先切入生产力场景。

### 观点三：不做基座模型，专注垂类场景构建差异化

**核心判断**：陈冕明确不做基座模型（2023年入局已晚），而是专注于多模态创作（设计/图像）的垂类场景，在非通用能力上构建竞争壁垒。

**具体解释**：基座模型需要顶尖科学家和巨额资金，且头部玩家已形成壁垒。应用层机会巨大，但要避开模型主轴，在特定场景（如设计）中打造模板、素材、画布+对话框的独特交互体验，聚集人类创意能力。

**案例或依据**：Lovart第一代产品定位图像生成，聚焦中国设计用户；第二代产品Lavert进一步深挖设计垂类，目标成为“设计的Cursor”。陈冕认为垂类agent活得很好，因为通用模型无法吃掉所有垂类场景。

### 观点四：创业时机和融资节奏决定生死，现金流管理是重中之重

**核心判断**：陈冕认为，创业失败最常见原因不是认知或业务错误，而是现金流管理差和融资节奏把握不当。

**具体解释**：时机和节奏至关重要。好的时机应扩大战果、做好充足准备；不好的时机所有事都不顺。融资需要准确估值、精准把握业务节点，做好融资窗口的管理。

**案例或依据**：第一轮融资估值报得太低（4000万美元应报5000万）；2023年产品被下架后，因不懂现金流管理导致账上只剩4000元，每天见3-4拨投资人却无人投资；2024年牌照和商业化起来后，一个月内完成三轮融资2000多万美元。这些经历让他深刻认识到现金流是创业生命线。

### 观点五：补贴战必须打，但要基于产品创新与“品效合一”

**核心判断**：在竞争激烈的AI应用赛道，补贴战是必选项，否则会被淘汰；但补贴只是管道，获客成本取决于产品创新和公众关注度带来的“品效合一”。

**具体解释**：虽然烧了300万美元主要用于补贴和GPU，但Lovart赢了竞争，成为图像生成赛道中国第一。陈冕认为，如果产品足够好、有创新，获客成本可以很低，因为能吸引免费的自然流量和用户口碑。

**案例或依据**：第一代产品获客成本仅3-4元人民币，原因是“中国用户需要这个，我们又是最好的”；以Kimi为例，陈冕认为如果模型智能能提升，免费流量更有价值，否则用户心智和习惯就是壁垒。

### 观点六：第二代产品（垂类Agent）时机已到，先发心智和冷启动是关键

**核心判断**：陈冕判断，2024年是“Agent大年”，垂类Agent爆发时机成熟，先发优势获取用户心智和冷启动流量是获胜关键。

**具体解释**：随着模型智能（如Claude 3.5）提升，垂类Agent的可行性大幅提升。Lovart第二代产品Lavert将创意表达门槛大幅降低，直接改变生产关系（甲方直接使用AI设计助理）。先发者能抢占用户心智，后续竞争者难以撼动。

**案例或依据**：Lavert上线后第二天推特阅读量从10万飙升至80万，随后在中国设计圈、AI圈爆火，Waitlist排队12万人。陈冕认为，垂类agent应做“垂类的第一个”，参考Cursor的先例。

### 观点七：垂类Agent独立存在，但通用Agent入口未来可能形成分发垄断

**核心判断**：垂类Agent可以独立生存并拥有深度用户群体，但通用Agent作为入口未来可能垄断大部分通用需求，并分发垂类需求。

**具体解释**：通用agent类似搜索或应用商店入口，能处理广泛任务，最终只会剩下少数玩家。垂类agent专注于特定场景（设计、视频剪辑等），用户粘性高。但如果AI极致发展突破AGI，垂类agent可能不再需要，因为一个通用agent就能做所有事。

**案例或依据**：GitHub类比——全球只需一个GitHub，coding赛道可能赢者通吃；而设计工具领域，Photoshop与Final Cut Pro并存，说明垂类领域巨头生态内仍有独立产品空间（如剪映）。

### 观点八：创业成就感远超大公司升职加薪，真正的回报是创造社会价值

**核心判断**：陈冕认为，创业带来的成就感远比大公司职级晋升有意义。职级只是管理手段，真正的成就感来自创造社会价值和改变世界。

**具体解释**：大公司用职级（reward model）作为激励机制，但创业者的动力来源于“用火柴在潮湿木头上反复滑动、直到燃起大火”的过程和结果。失败和绝境让人更理解人性，留下的人更珍贵，团队在周期中凝聚。

**案例或依据**：2023年底，创始团队20人走了一半，陈冕不怪他们，认为这是人性使然；自己在融资困难、账上只剩4000元时仍坚持；走红后独自手舞足蹈庆祝。他说“在黑暗中摸索越久，看到光越亮”是创业最爽体验。

### 观点九：给创业者建议——多做垂类、重视数据、不迷信产品、全面拥抱AI

**核心判断**：陈冕基于自身经验，给AI创业者提出多条实操建议，核心是聚焦垂类、重视行业认知、团队全面AI化。

**具体解释**：不要做通用模型；重视行业数据和认知；不要迷信产品经理（AI时代产品角色被解构）；团队全面拥抱AI工具；相信模型智能持续提升，提前准备；更早创业即使失败也更有收获。

**案例或依据**：AI时代团队结构简化，需要“教AI行业知识的人”和“会coding的人”，产品经理、传统前端/后端/测试角色被压缩。陈冕自评产品与战略是长板，但比张一鸣更感性，介于字节理性与小红书感性之间。

## 四、关键术语表

- **Agent / 智能体**：能自主理解任务、规划执行步骤并调用工具的AI系统。Lovart的Lavert即为设计垂类Agent。
- **垂类Agent**：专注于特定垂直领域（如设计、视频剪辑）的AI代理，与通用Agent相对。
- **MCP / 模型上下文协议**：Model Context Protocol的缩写，用于标准化模型与外部工具/数据源的交互，提升Agent工具调用能力。
- **Workflow / 工作流**：将多个AI模型或工具节点串联成自动化流程。早期产品让用户自己搭建节点（类似ComfyUI），但因设计群体不喜逻辑而失败。
- **扩散模型**：一种通过逐步去噪生成图像的生成模型，广泛应用于AI绘画领域。
- **多模态**：结合文字、图像、视频等多种信息形态的AI能力。Lovart定位多模态创作场景。
- **PMF / 产品-市场匹配**：Product-Market Fit的缩写，指产品找到稳定目标用户且需求被验证的状态。
- **ARR / 年度经常性收入**：Annual Recurring Revenue的缩写，订阅制模型下按年计算的经常性收入，衡量公司收入规模和健康度。
- **补贴战**：通过提供免费算力、拉新奖励等争夺市场份额的竞争策略。Lovart第一代产品期间参与补贴战并最终胜出。
- **品效合一**：品牌广告与效果广告结合，既建立品牌认知又能直接带来用户转化，降低获客成本。
- **冷启动**：新产品上线初期获取首批用户的过程。Lavert通过病毒传播一天解决冷启动。
- **终局判断**：用常识推理市场最终形态（如寡头或零散、供给或需求驱动），帮助避开错误路径。陈冕在字节期间学到这一方法。
